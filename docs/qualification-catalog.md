Highest completed qualification codes

Only completed qualifications are recorded. If several qualifications are at the same level, Admin selects the qualification to represent in the ID; the system does not guess. This is a broad organizational catalog, not a claim to list every degree worldwide. Admin can add qualifications with unique suffixes through Administration > Company catalogs. Runtime validation uses the stored catalog.

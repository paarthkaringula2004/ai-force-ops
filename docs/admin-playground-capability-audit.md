# Admin Playground capability audit

Checked against the requested 66 capabilities on 8 October 2026. Updated on 9 October with [API-based natural-language routing](admin-natural-language-routing.md). Each topic has guidance and an application link. Supported actions use existing confirmed or read-only server workflows; the remaining topics use dedicated controls or describe policy. Guidance is not evidence that an external integration is configured.

Describe the task in ordinary language, or choose **Admin actions** to browse Email, Requests, People, Security, Review Center, Operations or Agent Studio. Command examples below remain shortcuts; they are not required keywords. All 18 organization document templates are available through the document workflow.

Verification: all 66 exact labels and natural help questions, role isolation, seven navigation menus, destination pages/anchors and eAssist view names. Email and department workflows additionally have PostgreSQL rollback tests for confirmation, duplicate/replay prevention, audit and actual persistence. No external emails or infrastructure mutations are performed by these tests.

Remaining dependencies: Razorpay checkout is not implemented. ServiceNow incident actions require a configured connection. Scanning and automation require their configured integrations, workers and credentials. SMTP acceptance is not independent proof of inbox delivery.
